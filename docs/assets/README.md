# Logo

`logo.svg` is the Gitunia mark: a terminal window (blue outline and title bar with three dark window dots, dark body) with a branch icon centred in the body: a light trunk with two round commit nodes and a green branch line curving off it to a third node. Colours are the Catppuccin Mocha palette the UI uses (`docs/ux-look.md`). The blue outline keeps the tile visible on both light and dark GitHub themes. `favicon-32.png` and `favicon-180.png` are renders of it (`rsvg-convert -w 32 logo.svg -o favicon-32.png`).

Original work made for this project: no third-party assets or fonts. Licence: MIT, same as the repository (`LICENSE`).
